# Contribuer à pixel-pantry

Ce dépôt sert les images de mon blog. Il n'accueille pas d'images extérieures, mais les signalements
sont les bienvenus.

## Signaler un problème

Ouvre une [issue](https://github.com/Simon256px/pixel-pantry/issues) pour :

- une image qui ne s'affiche plus dans un article (donne le lien de l'article et celui de l'image) ;
- une capture qui laisse voir une information sensible (jeton, e-mail, adresse interne) : dans ce
  cas, ne recopie pas l'information dans l'issue, indique seulement le chemin du fichier ;
- une image dont tu détiens les droits et qui serait utilisée sans ton accord.

## Proposer une correction

Pour une image trop lourde ou mal nommée, une pull request est possible :

1. Forke le dépôt et crée une branche à partir de `main`.
2. Respecte les [règles de la cuisine](README.md#règles-de-la-cuisine) : kebab-case, compression,
   bon format.
3. Ne renomme pas une image déjà publiée : les articles pointent vers son chemin. Ajoute plutôt une
   nouvelle version (`nom-v2.webp`).
4. Explique dans la pull request ce qui change et pourquoi.
